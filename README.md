# Tofendo Admin Dashboard

Administrateur Dashboard pour la plateforme FinTech Tofendo en Guinée.

## 🚀 Fonctionnalités

- **Authentification** : Connexion avec email/mot de passe et vérification OTP
- **Tableau de Bord** : Métriques en temps réel (utilisateurs, transactions, volume, revenus)
- **Gestion Bancaire** : Intégration avec les banques et partenaires
- **KYC & Conformité** : Suivi des vérifications d'identité
- **Transactions** : Historique des transactions récentes
- **Taux de Change** : Affichage en temps réel des taux de change
